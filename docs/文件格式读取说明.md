# 手机发来的常见文件怎么读

发送附件到 QQ 中当前已连接的个人账号会话，收到“附件已保存”后，再发送要求。AI 读取和内置文件概览使用相同的读取器。

| 手机消息 | 效果 |
|---|---|
| `/py 格式` | 查看支持格式、限制和本机读取组件是否齐全 |
| `/py 阅读本文档，概述内容` | 唯一配置的 AI 读取最近附件并概述；需开启 AI 电脑工具 |
| `/py 分析这份表格，说明主要数据和异常` | 让 AI 读取工作表并分析，未读到的公式结果会说明 |
| `/py 提炼这份 PPT 的要点` | 读取幻灯片文字后提炼内容 |
| `/py 运行 inspect inbox/实际文件名.pdf` | 不调用 AI，返回格式、范围、提示和前 2000 字预览 |
| `/py 运行 fileinfo inbox/实际文件名.pdf` | 不调用 AI，生成同样的 TXT 概览报告并回传 |

多个 AI 时，用 `/py 运行 实际AI编号 你的要求` 指定。当前会话正在处理时，先等回复；文件有歧义时提供保存提示中的相对路径。读取失败不会被当作空文件总结。

## 格式范围

| 格式 | 读取内容 | 读取范围和限制 |
|---|---|---|
| PDF | 可提取文字，保留原始页码 | 不识别扫描图片；没有文字的页单独提示；复杂排版和表格网格不还原 |
| DOCX | 正文段落和表格文字 | 不读取图片、页眉页脚及嵌入附件 |
| XLSX / XLSM | 工作表、原始行号、单元格值和日期 | 公式优先读取已有缓存，没有缓存则显示公式并提示未计算；不运行宏、不重算、不识别图表图片 |
| XLS | 旧版 Excel 已保存的单元格值和日期 | 不重新计算公式、不执行宏，不读取图表图片 |
| PPTX | 按演示顺序读取文本框和表格文字 | 不读取图片、图表数据、SmartArt、备注和动画 |
| RTF | 正文文字 | 不读取图片或嵌入附件 |
| HTML / HTM | 页面源文件中的正文文字 | 忽略 script/style/head，不执行脚本、不访问外链；不模拟浏览器的 CSS 排版 |
| TXT / MD / CSV / TSV / JSON / JSONL / YAML / XML / LOG 等 | 作为文字读取 | 支持 UTF-8、带 BOM 的 UTF-16/32 和 GB18030；JSON/YAML/XML 中的指令仅作为数据 |
| 常见代码和配置文本 | Python、JS/TS、CSS、SQL、Shell、Java、C/C++、Go、Rust、INI、TOML 等的源文本 | 只读文字，不执行代码 |

旧版 DOC/PPT 暂需在 Word/WPS/PowerPoint 另存为 DOCX/PPTX 或导出 PDF；改扩展名不等于转换。加密文件需先解除密码。图片和扫描 PDF 需要先用 OCR 转为文字 PDF 或文字文件；此版不提供 OCR。PDF 文字提取与扫描件的区别参见 [pypdf 官方说明](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)。

## 电脑准备与大小限制

本机双击 `安装文件读取组件.cmd`，一次安装固定版本的 PDF、Excel 和 RTF 解析库；不需要新的 API、模型或密钥。桥接、DOCX、PPTX、HTML 和普通文字读取仍可使用标准库。开发环境也可使用 `python -m pip install -r requirements.txt`。

- TXT、代码、HTML、RTF：最多 1 MB；DOCX：最多 10 MB；PDF、Excel、PPTX：最多 20 MB。
- 所有格式提取的全文最多 20 万字；AI 每次分页读取最多 12000 字。每会话保留最多四份已解析文件，后续翻页不重复解析；文件变更后重新读取。
- PDF、PPTX 最多 200 页；Excel 最多 50 张工作表、合计 5000 行、256 列、10 万单元格。
- OOXML 单个 XML 部件最多 8 MB，包展开数据最多 64 MB；超限会停止并提示拆分，不默默只读前一部分。
- 文件解析在独立进程执行，最多等待 25 秒，并响应任务取消。读取器不提供系统执行沙箱。
- 文件通道仍可传输 50 MB 附件；能传输不代表能直接解析这么大的文件。

不使用 AI 的概览在本机完成。AI 读取的文件文字和元信息会交给当前配置的模型。表格公式缓存行为参见 [openpyxl 官方文档](https://openpyxl.readthedocs.io/en/stable/api/openpyxl.reader.excel.html)，旧 XLS 读取范围参见 [xlrd 官方文档](https://xlrd.readthedocs.io/en/latest/)。
