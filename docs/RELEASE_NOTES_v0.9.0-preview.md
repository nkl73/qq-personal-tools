# QQ Personal Tools v0.9.0 预览版

离开电脑，也能用手机 QQ 继续已接入的工作。QQ 是输入和收件入口，程序与文件仍在自己的电脑执行。

## 可以做什么

- 按编号选择功能、任务和文件；默认只接收最终答复与文件，必要提问、授权和错误仍会通知。
- 沿用电脑 Codex 登录，继续已有聊天、新建独立聊天或建立保留已保存上下文的手机分支；桌面应用可以保持打开。
- 通过手动安装的 Edge/Chrome 扩展连接已登录的 ChatGPT 普通网页聊天，选择现有页面或新建、多轮追问。
- 在电脑添加兼容 Chat Completions 的 API AI；可选择允许其读取共享文件、调用已授权工具并生成结果文件。
- 收发文件和图片，提取 PDF、DOCX、Excel、PPTX、RTF、HTML 与常见文字；可登记 Python 和命令行工具，也可接入受范围约束的项目修改与固定测试。
- 新版连接手机时默认防止自动睡眠，屏幕仍可关闭。实际锁屏下计算、Codex 分支和文件报告已通过手机验收。

## 首次使用

1. 下载本页源码 ZIP，解压到一个可写目录。需要 Windows 10/11 x64、Python 3.10+（含 tkinter）；这不是免 Python 的 EXE。
2. 双击“本机试用.cmd”，先体验不需要账号的计算、文字等工具。需要常用文档提取时运行“安装文件读取组件.cmd”。
3. 运行“安装后台组件.cmd”，按说明配置 QQ 后台；再运行“启动桥接.cmd”。普通电脑 QQ 需退出同账号登录，手机扫码确认后连接。
4. 在当前已连接的 QQ 个人账号会话发送 `/py 菜单`，按序号操作。此版本仅接受登录账号自己的私聊消息，不接受其他好友或群聊指令。
5. AI 通道按需接入：Codex 先在电脑安装并登录；API AI 在电脑“添加 AI”填写；ChatGPT 网页先在电脑生成本机配对扩展，手动加载、连接并刷新网页登录页面。

浏览器扩展只需安装一次，但必须使用自己电脑生成的配对文件；发布包里的扩展源码不能直接代替此步骤。详见[完整使用手册](完整使用手册.md)和[网页通道说明](ChatGPT网页通道.md)。

## 验证和边界

当前 Windows 本机完整 163 项自动检查通过。已有真实 QQ、API 工具、隔离项目修改、Edge/Chrome 网页及 Codex 代表流程的验证记录；锁屏三项手机收件也已确认。跨机、长期运行、睡眠恢复及所有模型/文档布局仍需分别验收。

电脑需保持开机联网。真正睡眠、休眠和关机时不能执行工作；保持唤醒功能不阻止手动睡眠或合盖。手机分支聊天记录不自动合并，项目文件仍共用。网页通道依赖页面适配，项目并未实现通用鼠标遥控、OCR 或任意终端接管。

源码包已排除账号配置、密钥、配对令牌、登录数据、聊天记录、用户文件、运行日志和本地 Git 历史，见[发布隐私检查](发布隐私检查.md)。第三方 QQ 后台及文件依赖需按说明另行安装，许可证见[第三方组件](../THIRD_PARTY.md)。
