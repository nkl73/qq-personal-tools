# 通过 API 在 QQ 使用 AI

本文只说明 API 通道，不是 ChatGPT 网页或 Codex。三种通道选择和编号操作见[完整使用手册](完整使用手册.md)，实际验证范围见[功能清单](功能清单与验证状态.md)。

本功能把已配置的 API AI 加入个人工具菜单。人在外面用手机提问和追问，电脑负责调用服务并把回复发回 QQ。可选开启电脑工具，让模型读取常见共享文档的文字、调用已授权程序、生成并回传文件。

## 电脑上准备一次

1. 打开新版个人任务面板，点击“添加 AI”。
2. 选择平台。火山方舟按量 API、DeepSeek、OpenAI 的地址由程序自动填写；其他兼容服务才需要填写地址。
3. 粘贴该平台的 API 密钥。支持读取列表的平台可点“读取模型”再选择，也可以直接填写模型名称。火山方舟填写控制台中已开通的模型或接入点 ID；此预设不使用 Coding Plan 套餐。
4. 点击“连接并添加”。程序发送一条短问题做测试，成功后自动加入 QQ 工具菜单；测试按服务商规则可能计费，失败时保留设置供修改。

需要文件和工具能力时，勾选“允许 AI 使用共享文件和电脑已授权工具”。模型需支持标准 function calling；此时连接测试会包含工具参数，服务不支持时会提示检查模型或关闭工具。旧配置默认关闭，不会自动增加权限。需要 AI 调用自己的普通 Python / 命令行工具时，编辑该工具并单独勾选“允许 AI 调用”。

名称、手机工具编号和等待时间自动设置，不需要自己填写。需要自定义名称、固定要求或等待上限时，再展开“更多设置”。编辑已有 AI 时，选中列表中的 AI，点击“编辑选中”，验证后保存。

模型列表只用于选择，不保证每个模型都支持此程序的文字接口；连接测试仍需通过。读取失败可以直接填写，程序不会静默选择收费模型或重复测试。

密钥默认只存在本次打开的程序内存中。Windows 可勾选“在本机加密记住密钥”，通过当前 Windows 用户的 DPAPI 加密后保存在本机 `.runtime/ai_profiles.json`。没有勾选时，重开面板后须在电脑补填密钥，其他配置仍保留。已加密的密钥不可跨用户或跨电脑直接搬用，解密失败须重新填写。其他系统暂时只有内存方式。

编辑时密钥框留空会沿用当前密钥。取消“记住密钥”并验证保存，会移除持久化的密钥密文，内存中的密钥在本次打开期间仍有效。删除 AI 配置会移除其配置和密钥；已经创建的会话使用启动时的配置快照，须结束会话才会释放该会话的凭据引用。

QQ 登录与连接操作和其他工具一致。电脑保持开机联网、面板保持运行即可，不需打开聊天窗口。密钥不要发到 QQ。问题、固定要求和最近上下文会发给你所配置的 AI 服务。

## 手机 QQ 上使用

推荐发 `/py 菜单`→“与 AI 对话”→“通过 API 新建 AI 对话”，按当前编号选择；回到菜单后用“继续本次打开的 AI 对话”选回。文件处理优先从文件菜单选实际文件→“选择 AI 处理这个文件”，只列出已开启工具的 API AI。以下指令为保留的直接操作方式。

默认 QQ 只回最终答复、文件和必要问题、错误；不会重复发送“等待提问”或在结束时重播整段对话。`/py 消息` 可按序号选择详细模式；任务菜单可查看结果与执行详情。

以下假设自己实际设置的 ID 是 `ai`，任务编号是 `a1b2c3d4`；真实编号可在任务菜单查看，也可全程按序号选择。

| 手机发送 | 电脑和 QQ 的反馈 |
|---|---|
| `/py 菜单 工具` | 列出这台电脑真正配置的 AI 和其他工具 |
| `/py 帮助 ai` | 查看此 AI 的启动、追问和结束方法 |
| `/py 运行 ai 帮我起草一封请假邮件` | 创建新会话，返回 AI 文字答复 |
| `/py 回复 a1b2c3d4 改得简短一些` | 在原会话中继续，模型可以看到近期上下文 |
| `/py 选择 a1b2c3d4` | 选中会话，之后可用 `/py 你的问题` 回答它 |
| `/py 状态` | 查看正在生成、等待提问或已经结束的会话 |
| `/py 结果 a1b2c3d4` | 查看本机保存的近期文字记录 |
| `/py 结束 a1b2c3d4` | 当前回答结束后正常退出并释放名额 |
| `/py 取消 a1b2c3d4` | 请求停止本地请求进程并结束会话 |
| `/py 菜单 AI` | 查看完整 AI 使用说明 |

也可以先发 `/py 运行 ai`，等收到“等待提问”后再回答。每次发送“运行”都会新建独立会话；连续追问使用“回复”，避免重复开新会话。有多项 AI 时，按各自工具 ID 启动。各会话互不分享历史。

只有一个 AI 且未选中活跃任务时，也可直接发 `/py 阅读本文档，概述内容` 或其他自然语言要求，自动开始新会话。已选会话等待提问时继续它；旧任务结束后自动清除旧选择并新建会话。正在处理或排队时会提示等待，并明确告知新内容尚未提交。多个 AI 时返回选择示例，不自动猜模型；缺少密钥时提示在电脑补填。

接口出错会返回易读提示，不自动重发。普通文字请求失败时不加入上下文；已执行电脑工具后模型出错时，本轮操作和结果会保留，请先检查任务状态，避免重复运行。现有会话采用启动时的模型和密钥快照，修改后须结束旧会话、重新运行；关闭工具开关或撤销某程序授权后，会阻止后续工具请求。正在运行的程序可用取消指令停止。

## 用自然语言处理文件和调用程序

1. 在手机 QQ 中当前已连接的个人账号会话发送 PDF、Word DOCX、Excel、PPTX、RTF、HTML 或常见文字，等收到“附件已保存”。
2. 启动已开启工具的 AI：`/py 运行 ai 把最新收到的 TXT 整理成待办清单，保存为文件发给我`。
3. AI 查询共享文件的名称与时间，读取内容，使用可用工具。QQ 会显示每次工具名称，以及启动程序的子任务编号、进度和错误。
4. 生成的文字结果文件和成功程序的结果附件会自动排队回传；普通回答仍是文字消息。已有文件也能按你的要求直接发回。
5. 继续工作用 `/py 回复 实际AI会话编号 新要求`。查询、取消子任务使用它自己的编号；取消 AI 会话会同时停止正在运行的子任务。

可调用的工具为：`list_tools`、`list_files`、`read_file`、`run_tool`、`task_status`、`cancel_task`、`write_text_file`、`send_file`。你只需用自然语言描述要求。它只看到授权工具的名称和输入说明，不接收程序路径、固定启动参数或密钥。

`run_tool` 在父 AI 的工作名额内运行，等待程序返回后把真实输出交给模型。两个 AI 会话同时调用程序也能执行。交互式程序仍由你按原方法直接启动和回答，暂不交给模型自动操作。

文件读取支持 PDF、DOCX、XLSX/XLSM/XLS、PPTX、RTF、HTML、常见文字及代码。文字最多 1 MB，DOCX 最多 10 MB，PDF/Excel/PPTX 最多 20 MB；全文最多 20 万字，每页 12000 字。表格保留工作表与原始行号，PDF/PPTX 保留页码；空白或扫描页和缺失公式结果单独说明。电脑双击“安装文件读取组件.cmd”准备 PDF/Excel/RTF 组件；手机用 `/py 格式` 查看状态，完整限制见[文件格式读取说明](文件格式读取说明.md)。列表返回最近修改的 100 个文件（最多扫描 1000 项）。写入支持 TXT/MD/CSV/JSON，内容最多 12000 字，只在 AI 会话结果目录新建文件，不覆盖原文件；每会话最多自动生成并回传 10 个结果文件。文件通道本身仍是单文件 50 MB、直接图片 10 MB。

单轮最多 8 次模型请求和 12 次实际工具操作，同轮相同工具及参数复用结果。整轮等待上限为单请求等待时间的 3 倍，最低 30 秒、最高 600 秒，子程序也受剩余时间约束。工具结果较多时会按完整用户轮次裁剪历史，避免丢失调用与回执的对应关系；本轮工具上下文超过约 120000 字符时停止并提示缩小范围。

开启后，读取的文件和工具输出会发送给所配置的模型服务。已有程序保留正常运行权限，参数中的业务行为由程序决定。AI 没有任意 shell、临时可执行程序、桌面点击、修改配置、网页搜索或图片识别入口。

若需要改动具体项目，可登记 `project_tool.py`，在电脑配置可编辑清单与只读固定测试。模型通过它实际改写源码、查看差异、执行固定验证并回传交付包，接入步骤见[项目工具使用说明](项目工具使用说明.md)。已用真实 deepseek-flash 完成隔离报价项目验收：仅源码改变，固定测试未变，8 项测试全部通过，手机收到差异、报告和源码 ZIP。其他业务项目仍须单独配置并验证。

## 适用范围

- 文字问答、起草、翻译、润色、解释代码与分析你发来的文字。
- 仅支持 Chat Completions 兼容接口，不声称支持任意 AI API 或所有模型。原生 Responses、原生 Messages、图片/语音接口等需要单独适配。
- 未开启工具时为文字对话；开启后只使用上述共享文件与已授权工具。常见文件可直接读取文字；旧 DOC/PPT 需转换为新格式或 PDF，图片和扫描件仍需 OCR。读取文件不代表完整还原布局、图表和嵌入附件。
- 每次提问最多 12000 字；发给模型的历史最多最近 20 轮、约 48000 字，旧轮次会逐步移出。服务商的上下文限制仍可能更小；长文宜分段或新建会话。
- 回复超过 24000 字时截断并提示；服务端达到输出上限也会提示。文字记录仍受整个面板的保存长度限制，不提供完整历史恢复。重开面板后原会话无法恢复，未结束任务记为中断。
- 同时最多两个活跃任务；等待提问的 AI 会话也占一个名额，用完请结束。请求期间会显示运行状态，当前不提供逐字流式输出。
- 取消会停止本地请求，不保证远程服务已经停止生成或停止计费。测试和普通提问都没有自动重试。
- 密钥只用于请求鉴权，不放在地址、QQ 菜单或子进程命令参数里。远程 HTTP 不允许，重定向不会携带凭据跟随。错误不直接转发服务商响应正文。若模型原样回显已配置密钥，会遮盖后再保存和回传；无法保证识别编码或变形后的秘密。

接口字段依据 [OpenAI 官方 Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)与[工具调用文档](https://developers.openai.com/api/docs/guides/function-calling?api-mode=chat)。兼容服务仍应以各自官方文档给出的地址和模型 ID 为准。AI 工具功能经过本机 HTTP 模拟模型、真实 Python 子进程和模拟 QQ 完整文件上传测试；另已使用用户配置的真实 deepseek-flash 完成“读取文件→调用计算与文件概览→生成结论→QQ 回传”的联合验收，手机确认两份附件及内容正确。连续追问也已验证。具体范围与其他未验证项见[验证记录](validation.md)。

简化设置的预设地址和模型列表依据：[火山方舟官方第三方工具接入](https://docs.volcengine.com/docs/ark/integrate-third-party-tools?lang=en)、[DeepSeek 官方接入说明](https://api-docs.deepseek.com/)、[DeepSeek 模型列表](https://api-docs.deepseek.com/api/list-models/)、[OpenAI 官方模型列表](https://developers.openai.com/api/reference/resources/models/methods/list)。
