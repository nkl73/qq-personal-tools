# QQ Personal Tools 完整使用手册

版本：v0.9.0 预览版；核对日期：2026-10-25。目标是离开电脑后，用手机 QQ 继续已经接入的工作。电脑负责执行，文字、进度和文件通过自己的 QQ 个人账号会话返回。

本手册按“准备→操作→反馈→限制”说明功能。真实验收到什么程度请看[功能清单与验证状态](功能清单与验证状态.md)，不是所有入口都已完成真实模型验收。

## 1. 先选需要的功能

| 想做什么 | 电脑需要准备什么 | 是否需要浏览器扩展 |
|---|---|---|
| 算式、文字统计、文件概览、文件往返 | Python、面板和 QQ 后台；部分格式需读取组件 | 否 |
| 运行自己的 Python/命令行程序 | 在面板登记程序、解释器和参数，先验证该程序 | 否 |
| 使用 API AI、读文档、调用已授权工具 | 电脑“添加 AI”配置平台、密钥和模型；文件/工具能力另开启 | 否 |
| 通过 ChatGPT 已登录网页聊天 | Edge/Chrome 登录 ChatGPT、生成并手动加载本机扩展 | 是，只对这一项需要 |
| 继续或新建 Codex 会话 | 电脑安装并登录 Codex；已有项目；原会话占用需交接；更广项目操作仍实验 | 否 |

内置离线工具不调用模型；接入 API AI 的测试和请求按所选服务规则可能产生费用。源码包不附带 Python、已登录 QQ、Codex、模型账号或配对后的扩展。

## 2. 第一次安装到收到回复

### 2.1 先在电脑验证程序可运行

1. 准备 Windows 10/11 x64 和 Python 3.10+，Python 需包含 tkinter。当前主要实测环境是 Windows、Python 3.14.3。
2. 将源码包完整解压到可写文件夹，不在压缩包内直接运行，不移动单个脚本使用。
3. 双击 `本机试用.cmd`；选“计算器”，输入 `12*(3+4)`，点击“运行选中工具”。
4. 任务应完成，结果为 `84`。这一步不需要 QQ 或模型；失败时先解决本机环境问题。

若要读取 PDF、Excel 或 RTF，再双击 `安装文件读取组件.cmd`；DOCX、PPTX、HTML、常见文本的基础读取无需这些可选库。自己程序需要的包，要装到该工具选定的解释器中。

### 2.2 连接手机 QQ

1. 双击 `安装后台组件.cmd`，等待下载并校验托管 QQ 后台。它使用独立 `.napcat` 文件夹，不打包在源码中。
2. 普通电脑 QQ 的同账号退出登录；手机 QQ 保持登录。
3. 双击 `启动桥接.cmd` 打开新版面板。如果还在“本机试用”，先停止它。
4. 面板点“QQ 登录”，手机扫码并确认；再点“连接手机”。当前步骤须手动完成，不是自动安装向导。
5. 手机进入当前已连接的 QQ 个人账号会话，发 `/py 菜单`，应收到使用菜单。以实际有回复的个人账号聊天为准，不要求某个设备传输助手名称。
6. 手机发 `/py 菜单`，按当前编号选择“运行电脑工具”→“计算器”，提交 `/py 12*(3+4)`，应收到 `84`。

已有本机 OneBot 后台可按[连接说明](onebot.md)配置地址、签名 Token 和自身消息回调，不必重复使用托管实例；不保证所有第三方实现的文件事件兼容。

**当前聊天入口说明：** 本版使用 QQ 个人账号会话，不要求“我的电脑／我的手机”设备传输助手。程序校验本机登录账号自身的私聊消息，不识别聊天标题；本文后续统一称“当前已连接的 QQ 个人账号会话”。不是让任意好友私聊这个账号就能控制电脑，其他联系人和群聊仍被忽略。账号编号不必发到公开 Issue 或使用截图中。

离开前保持面板运行、电脑联网和供电；面板可最小化，不要求普通 QQ 聊天页前台。新版默认勾选“连接手机期间防止自动睡眠”，停止连接后解除，屏幕仍可关闭。锁屏下计算、Codex 分支和文件回传已有手机确认；真正睡眠会暂停程序，手动睡眠/休眠/合盖仍可能中断。不同电源策略与长时间运行仍需验证，不要把关闭窗口当成最小化。见[锁屏与睡眠说明](锁屏与睡眠验收-20261025.md)。

## 3. 手机菜单和输入规则

每条操作文字带 `/py` 前缀；直接发附件不加前缀。若电脑更换了前缀，以实际菜单为准。

| 首页项目 | 用法和反馈 |
|---|---|
| 与 AI 对话 | 选择 ChatGPT 网页、API 新对话，或继续本次打开的 AI 对话 |
| 继续电脑 Codex | 继续默认会话、选择其他已有会话，或新建独立会话 |
| 运行电脑工具 | 按列表选择；有内容或文件参数时继续提示选择/输入 |
| 选择文件进行处理或取回 | 选共享文件，再选概览、TXT 报告、API AI 处理或取回原文件 |
| 查看任务、结果或继续对话 | 按任务条目看结果、返回等待输入的对话、结束或停止 |
| 使用说明与支持格式 | 查看任务、对话、文件、AI、问题与本机格式组件状态 |

发 `/py 菜单` 随时打开首页；用 `/py 1` 这样的当前编号选择。菜单每页最多六项；有分页时按提示的 7/8 翻页，0 返回。选择 5 分钟后失效，不执行旧选择。首页 0 返回原来选中的对话。

选择菜单打开时，数字是菜单选择，不是程序回答。回到对话后数字才能作为输入。收到回答或新的问题后可继续；运行中追加文字不会自动排队为下一次提问。若工作内容恰好是“菜单”“状态”等指令词，使用 `/py 回复 实际任务编号 内容`。

默认简洁消息：QQ 主要接收答复、文件与必要问题、授权和错误，不重复发送接受回执、工具步骤和等待提示，结束时不重播聊天记录。发送 `/py 消息` 按序号选择简洁或详细，选择会保存在本机。任务菜单可按需查看“文字结果”和“执行详情”；任务编号和工具日志仍保存在电脑，多个活跃任务时回复会注明归属。

## 4. 内置工具

| 功能 | 手机操作示例 | 反馈与做到的程度 |
|---|---|---|
| 电脑状态 | `/py 设备` | 系统、Python 和磁盘剩余空间；不是远程桌面 |
| 算式 | `/py 运行 calc 12*(3+4)` | `84`；常规数值算式，不运行 Python 语句 |
| 文字统计 | `/py 运行 text 这是测试内容` | 字符、汉字、英文单词、行数 |
| 文件列表 | `/py 文件` 或文件菜单 | 共享目录非隐藏文件，最多 100 个；不扫描整个电脑 |
| 文件概览 | 文件菜单→文件→查看文件概览 | 格式、统计、缺失提示和少量文字预览，不是 AI 总结 |
| TXT 概览报告 | 文件菜单→文件→生成并回传 TXT 概览报告 | 任务完成后收到“文件概览.txt”附件；不改原文件 |
| 进度演示 | `/py 运行 demo 10` | 约 10 秒演示，收到进度和完成消息，可从任务菜单停止 |

没有配置 AI 也能运行以上工具。需要具体业务转换、构建等能力时，须登记对应程序。

## 5. 手机文件与电脑文件往返

1. 手机直接发送文件/图片到当前已连接的 QQ 个人账号会话，等待“附件已保存：inbox/…”；发送成功图标不等于电脑已经落盘。
2. 发 `/py 菜单`→“选择文件进行处理或取回”→按文件名选择。
3. 选概览、TXT 概览报告、API AI 处理或取回原文件。选 AI 处理时还需选择可读文件的 AI 并描述要求。
4. 成功生成的任务结果另以附件回传；手机确认下载/打开后再认为交付完成。

`/py 发文件 inbox/实际文件名.pdf` 可手动取回原格式附件，`/py 发图片 inbox/实际图片名.png` 可直接显示图片。相对文件名可有空格，按保存提示整段填写，不使用手机本地路径。也可把文件放进电脑面板的“共享目录”后从手机选择。

单文件最多 50 MB；直接图片 PNG/JPEG/GIF/WebP 最多 10 MB；inbox 最多 500 MB，满后要在电脑整理。同内容再次上传允许保存，同名不覆盖。压缩包仅传输，不自动解压或执行。失败/取消任务的现有文件不会自动回传，可检查后手动取回。

自建工具只有写进本任务输出目录的文件才自动收集，每次成功任务最多 10 个；不会跟随终端打印路径去找文件。“未确认”可能实际已发送，先看手机，避免重复。完整设置见[文件通道说明](文件通道使用说明.md)。

## 6. 常见文档能读到哪里

| 输入 | 当前读取内容 | 不包含的内容 |
|---|---|---|
| PDF | 可提取文字，保留原始页码和缺失页提示 | 扫描图 OCR、原版面、复杂表格网格 |
| Word DOCX | 正文段落、超链接显示文字、表格 | 图片、页眉页脚、嵌入附件 |
| Excel XLSX/XLSM/XLS | 工作表、行号、已保存值与日期；XLSX 无缓存的公式提示未计算 | 自动重算、宏执行、图表识别 |
| PPTX | 演示顺序中的文本框、表格文字 | 图片、SmartArt、图表数据、备注、动画 |
| RTF / HTML | 正文文字；HTML 不执行脚本、不访问外链 | 完整排版、图片、嵌入附件 |
| 文本与源代码 | TXT/MD/CSV/TSV/JSON/JSONL/YAML/XML/LOG 及常见代码/配置源文本 | 自动执行代码、数据格式中的指令授权 |

文字/HTML/RTF 最大 1 MB，DOCX 10 MB，PDF/Excel/PPTX 20 MB；全文最多 20 万字。PDF/PPTX 200 页，Excel 50 张表、合计 5000 行、256 列、10 万单元格。AI 每次读取最多 12000 字，长文可能需要多次读取/继续提问，不能把一轮回答当成保证读完全文。

发 `/py 格式` 看组件状态。加密文件先解密；旧 DOC/PPT 在办公软件另存为 DOCX/PPTX 或 PDF，改文件名后缀无效。扫描件需先自行 OCR；当前无 OCR。详见[文件格式读取说明](文件格式读取说明.md)。

## 7. API AI：配置、提问、追问和结束

电脑点“添加 AI”→选平台→填该平台 API Key→读取模型列表或填写模型→“连接并添加”。预设填地址，不代表任意 API 都兼容。只支持 Chat Completions 兼容文字接口；火山方舟需已开通的模型/推理接入点 ID。密钥只在电脑填，普通文字提问不需开启工具。

手机：`/py 菜单`→“与 AI 对话”→“通过 API 新建 AI 对话”→按模型条目选择→等待提问→发 `/py 帮我整理一份待办清单`。收到回复后继续 `/py 改成按优先级排序`，当前会话保留近期上下文。回首页后可用“继续本次打开的 AI 对话”选回；另选新建则开启独立会话。

模型回复是文字，当前不逐字流式输出。每次问题最多 12000 字，保留最近最多 20 轮/约 48000 字，超长回复最多 24000 字并提示。重开面板不恢复 API 内存对话；任务记录保留不等于模型还能看到全部历史。API 对话不进入 ChatGPT 网页历史。

从任务菜单“结束这次会话”会等当前回答完成再释放名额；“停止这个任务”立即请求停止本地请求，不能保证远程停止生成/计费。测试和请求不自动重试。密钥默认内存，Windows 可选“在本机加密记住密钥”，仅当前用户可解密。详见[API AI 使用](AI接入与QQ使用.md)。

## 8. API AI：文件、工具与项目改动

### 8.1 文件和授权程序

在电脑 AI 设置勾选“允许 AI 使用共享文件和电脑已授权工具”；模型需支持 function calling。若要运行自建普通 Python/命令行程序，再在那个工具上勾选“允许 AI 调用此工具”。

手机发文档、等保存提示，然后从文件菜单选择“选择 AI 处理这个文件”→选 AI→发 `/py 概括主要观点，并把结果保存为 TXT 发给我`。QQ 会显示读文件/运行工具、子任务编号、结果或错误，成功生成的 TXT/MD/CSV/JSON 文件自动回传。直接用自然语言指“本文档”时可能有多个候选，编号选文件更明确。

AI 可以列/读共享文件、运行授权工具、看/停自己的子任务、生成新文字文件和发送共享附件。它不能因为一句话就获得任意程序、整个磁盘、其他 AI 会话或鼠标操作权；ChatGPT 网页通道不继承这些权限。每轮最多 8 次模型请求、12 次工具操作，最多等待 10 分钟；新文字文件每份最多 12000 字，每会话最多 10 份，不覆盖已有文件。复杂任务分轮继续。

读到的文字和工具输出会发送给所选服务。AI 的“已完成”文字不能替代真实附件或测试结果；失败时看工具回执。具体边界和示例见[API AI 使用](AI接入与QQ使用.md)。

### 8.2 修改项目

先在电脑按[项目工具说明](项目工具使用说明.md)登记 `project_tool.py`，配置项目根目录、可编辑/可读文件和只读固定测试，选择解释器并授权。该功能需要准备配置与测试，不是点一下就能安全修改任意项目。

手机选已开启工具的 API AI，提出“给已登记的订单计算项目增加折扣和运费，修改后运行固定测试，通过后发回差异、测试报告和源码包”。模型读取实际文件，按旧哈希替换已授权源码，运行固定测试，再导出。

应收到 `project-changes.diff`、`project-validation.txt`、`project-source.zip`。打开报告检查 `passed` 与测试输出；源码包只含允许读取的文件，不一定包含整个项目或运行依赖。单文件 64 KB，已有 UTF-8 文件可改，测试文件不能改。修改后旧测试结果失效；导出要求当前文件仍匹配通过测试时的内容。备份与差异保存在电脑，恢复需核对，不自动回滚。运行项目测试仍使用当前用户权限。

## 9. ChatGPT 网页：安装扩展和手机聊天

此通道沿用浏览器登录，不需要 API Key；只有这一通道安装扩展。当前是手动加载本机扩展，没有自动安装向导或免安装商店版。

1. 保持面板运行并连接 QQ；在 Edge/Chrome 手动登录普通 ChatGPT 网页，确认自己能聊天。
2. 面板点“ChatGPT 网页通道”，程序生成这台电脑专用的扩展并打开 `extension` 文件夹；也可运行 `准备ChatGPT网页通道.cmd`。
3. Edge 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），手动开启开发人员模式，选择“加载解压缩的扩展”，选刚生成的整个文件夹。
4. 点浏览器右上角“拼图”→“QQ Personal Tools · ChatGPT 网页通道”，在白色弹窗点“连接此浏览器”，再刷新 ChatGPT。扩展管理的“详细信息”页面没有此连接按钮。仅安装或“已启用”还不等于手机收发已通过。
5. 手机菜单→“与 AI 对话”→“ChatGPT 网页”→新建或选择已打开聊天→收到“已选择”提示后，才发送工作要求。
6. 先发一个中性短问题，确认手机收到答复；再追问，确认同一网页上下文。浏览器不用放前台，不能关闭。

选择聊天本身不向网页发送工作内容。继续发 `/py 你的追问`；发 `/py 切换`回选择页，发 `/py 新建`开启新普通聊天，发 `/py 退出`结束当前网页桥接。主菜单打开后先按首页 0 返回，或从任务菜单选回，避免内容被当成菜单操作。

旧聊天需先在电脑浏览器打开普通 `/c/` 页面，再从最多 8 个标签页中选择；不搜索全部历史，不支持自定义 GPT/其他专用页面。只有文字通道，没有 QQ 附件自动上传、本机工具调用或网页工具授权代点。

草稿、已有生成、页面跳转或无法确认答复归属时会停止并提示，不覆盖、不自动重发。面板取消不保证网页生成停止；遇到不确定先去网页确认。页面变化可能要更新扩展，登录验证需自己完成。程序更新后重新生成扩展、浏览器管理页“重新加载”、刷新 ChatGPT；扩展“断开”停止新请求。

发布只包含扩展源码；每台电脑自己生成配对信息，不使用别人已配对的文件夹。Edge/Chrome 本轮均有真实新建、追问、重选旧聊天与回传记录，Chrome 另作纯后台复核；跨机仍需验证。完整说明见[网页通道](ChatGPT网页通道.md)。

## 10. Codex：已有会话与新建

电脑先安装、登录 Codex 并打开过项目。手机首页→“继续电脑 Codex”：

- **继续已有会话**：选默认/其他会话，确认继续原聊天后提交要求。原聊天被占用时可选择手机分支，或释放其连接后明确“重试”；仅最小化或等回答结束可能不够。等待中的要求不会自动重发，可选择“取消请求”。
- **手机分支**：选已有会话后选择“建立手机分支”，沿用已保存上下文、模型和项目，桌面可以保持打开；聊天记录不自动合并，项目文件仍共用。原会话占用时也可明确选择分支处理刚才尚未提交的要求。
- **新建独立对话**：选已有项目目录、可用模型/默认模型、确认创建；收到新会话编号后再发送具体要求。创建不复制旧历史，不是新建空项目。项目与模型列表来自本机接口。

默认只回最终文字与必要提问、确认和错误；详细模式可看进度。按显示内容处理确认/拒绝，不是永久放开权限。任务菜单可以看结果、详情、继续、结束或取消，取消只针对桥接启动的轮次。

此通道是独立本地接口，不是对桌面窗口模拟输入；同一原会话不能保证同时由桌面和桥接写入。当前没有 Codex 项目附件自动收集，必要时通过普通共享文件通道取回。`/py 回复 实际任务编号 结果` 是让 Codex 读取最近已保存答复；`/py 结果 实际任务编号` 是查看桥接保存文字，两者不同。

**本轮已实际复测 Codex 继续/新建读文件、隔离项目修复并测试、单次同意/拒绝及取消。** 此前用户两种方式的读取确认仍保留；更多业务项目、模型与权限场景需分别验证。系统代理继承和新建首条消息的问题已修复，见[Codex 说明](QQ继续电脑Codex.md)与[本轮报告](全功能测试报告-20261025.md)。

## 11. 自己的 Python 与命令行工具

电脑“添加本机工具”中选择运行方式，填写 ID、名称、用途、程序路径；Python 程序选择正确解释器，必要时设工作目录、等待上限、输出编码。参数一行一个，先在电脑验证相同输入能正常运行。

| 类型 | 适合情况 | 手机和反馈 |
|---|---|---|
| 普通 Python 任务 | 一次提交参数，运行结束 | 工具菜单选工具、填内容，返回进度与最终输出 |
| 交互式 Python | 多步 `input()` / `print()` | 按程序每次提示逐项回答，进程在会话间保持 |
| 已安装命令行程序 | 本机已有转换、分析、构建工具 | 按登记的可执行程序和参数启动；依赖自行安装 |

`{text}` 是本次内容的一个原样参数；`{file}` 将选中共享文件转换为电脑完整路径；`{output}` 是本任务结果目录。自己程序也可读 `QQ_BRIDGE_SHARED_DIR`、`QQ_BRIDGE_OUTPUT_DIR` 环境变量。把预备交付的文件写入输出目录，任务成功结束后自动回传，交互程序须真正结束才收集。

`getpass()` 提示只在电脑选中对应任务提交隐私值，QQ 只看到等待提示；离开前完成必要秘密输入。输出遮盖只覆盖已提交的原始秘密等有限情况，不保证识别变形或程序自行读取的其他秘密。

不是所有 `.py` 都能直接接。已有终端进程、全屏 TUI、要求真实 TTY、GUI 鼠标交互或不兼容输入机制的程序需专门适配。手机不能提交临时任意命令。旧 `启动单脚本.cmd` 只保留一个交互脚本的文字收发，没有新版文件/多工具菜单，见[兼容说明](single_script.md)。

## 12. 状态、结果、取消与重启

任务菜单按条目选择即可；保留的直接指令如下，编号使用实际收到的值：

| 指令 | 结果 |
|---|---|
| `/py 状态` | 近期任务及状态；“已创建”仅表示接收，不是执行成功 |
| `/py 结果 实际任务编号` | 最近保存的文字输出 |
| `/py 选择 实际任务编号` | 选中等待输入的任务，之后可直接提交内容 |
| `/py 回复 实际任务编号 内容` | 明确向此任务回答；空内容可给交互程序回车 |
| `/py 结束 实际任务编号` | AI/Codex/网页会话当前回答结束后退出 |
| `/py 取消 实际任务编号` | 请求停止本地任务/它启动的进程树；副作用不回滚 |

活跃最多 2 项（等待输入也算），另排队最多 20 项。没有进度可能是程序没输出，不能因此反复启动。完成、失败、超时、取消和中断都可查询。本机最多保存最近 24000 字，完成通知最多最近 6000 字，手机查结果最多最近 12000 字，不是永久完整日志。

重启后旧未完成任务标为中断，不自动重跑；API 内存上下文、待提交输入不恢复。已保存文件仍在共享目录，网页记录与 Codex 历史在各自系统；重新选择不代表恢复了旧后台执行。密钥只在内存时须重新填，本机加密记住的凭据只适用于当前用户。升级前保存工作、结束任务、备份自己需要的文件，不把运行中的程序目录直接覆盖。

## 13. 常见问题

| 看到的情况 | 先做什么 |
|---|---|
| QQ 连菜单也不回 | 查电脑是否开机联网、面板是否连接、是否发到当前已连接的 QQ 个人账号会话、前缀是否正确；检查后台登录 |
| 已创建但没结果 | 菜单→任务，看排队/运行/等待输入/失败；不要重复运行 |
| “没有等待这种输入” | 旧任务可能结束、正在处理或需要电脑隐私输入；从菜单选回任务，等当前提示再答 |
| 文件不能读 | 发 `/py 格式`，查格式、解析大小、可选组件；图片/扫描页需另行 OCR |
| AI 看不到文件/不能运行工具 | 确认是 API 通道，AI 和自建工具均已授权；先按文件菜单选择实际文件 |
| 网页扩展启用但不回复 | 确认面板连接、浏览器登录、页面已刷新、选中普通聊天；看任务错误和网页，不盲目重发 |
| Codex 占用 | 按提示选择手机分支，或释放原会话连接后明确重试；桌面可保持打开，分支聊天记录不合并；此链路仍实验 |
| 后台说已发但手机没下载 | 先看 QQ 实际消息和网络，回执不是下载成功；未确认不自动重发 |

不支持群聊/其他联系人遥控、微信、OCR、任意图形应用控制、电脑关机后工作或自动恢复/回滚。托管组件、QQ、Codex 和外部程序使用各自的许可和账号，见[第三方说明](../THIRD_PARTY.md)。当前程序以本机用户权限运行；登录、密钥、本机配对配置和共享私人文件不属于可公开发布的源码。
