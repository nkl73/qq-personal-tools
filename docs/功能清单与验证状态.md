# v0.9.0 功能清单与验证状态

核对日期：2026-10-25。适用于新版个人任务面板。此表描述当前源码和已经取得的证据，不把功能入口存在或自动检查通过等同于真实手机验收。

用户从[完整使用手册](完整使用手册.md)开始；维护者按[发布前验收清单](发布前验收清单.md)补齐未验收部分。历史实测记录见[验证记录](validation.md)。

QQ 入口以当前实际使用的**个人账号会话**为准，不是固定的设备传输助手名称。接收范围仍是本机登录账号自己的私聊消息；文本和文件代码均按账号校验，未开放其他联系人或群聊。

## 验证标记

- **手机实测**：本机实际连接 QQ/模型/浏览器，用户确认手机结果；只覆盖表中场景。
- **用户确认**：用户直接报告自己已完成的测试，按其说明记录范围；不冒充本轮由维护者重新观察的记录。
- **本机实测**：实际运行组件或程序，但没有对应完整手机确认。
- **自动检查**：真实本机进程、HTTP 或模拟外部服务的回归检查，不代表外部账号全流程通过。
- **待验收**：尚无完整证据。不能在发布说明中写成“全部通过”。

## 不能列入“已支持”的能力

以下能力当前没有通用实现：微信桥接、现有 VS Code 终端接管、任意图形应用/鼠标遥控、手机临时提交任意命令执行、OCR/图片理解/语音处理、自动解压附件、内置联网搜索、关闭电脑仍继续运行、任务和副作用自动回滚、全部聊天历史同步、免 Python 的 EXE 安装包、自动安装浏览器扩展、一套向导完成全部安装。

登记外部工具后可能获得某些额外能力，但应作为该工具的独立能力和验收，不归为桥接内置功能。ChatGPT 或 Codex 本身拥有的能力，也不等同于桥接已支持对应结果/附件/授权交互。

## 发布时应如何表述

可表述为“面向 Windows 的个人 QQ 工作桥接预览版，提供编号菜单、文件往返、兼容 API AI、可选 ChatGPT 网页通道，以及用户已确认读文件/文字回传的 Codex 继续与新建会话”。Codex 项目修改、授权和取消等更广工作场景保留实验标记。已有自动检查和本机手机实测不代表全型号、全模型或长期稳定性验证。当前还不能宣称“所有功能完成真实验收”“支持所有 Python”“全平台”“完全无人值守”或“安装无需手动操作”。
