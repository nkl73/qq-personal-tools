# 从手机 QQ 修改项目

项目工具是可登记的普通 Python 程序。它只操作电脑配置中的文件，提供读取、完整文件替换、差异、固定测试和导出。模型仍通过现有 run_tool 调用，不需要新模型接口或插件。

## 电脑准备

在本机私有目录建立 JSON 配置，例如 `.runtime/my-project.json`：

```json
{
  "root": "C:/path/to/your/project",
  "editable": ["src/calculator.py", "README.md"],
  "readable": ["requirements.txt"],
  "test_script": "tests/verify_project.py",
  "test_timeout": 45
}
```

把路径替换成自己的实际项目和已有文件。`editable` 明确允许覆盖的文件；`readable` 是其他可读文件；固定测试脚本自动加入可读清单，不能同时列入 editable。只支持已有 UTF-8 文件，单文件最多 64 KB。隐藏路径、越界路径和目录链接不接受。

离开电脑前，保存初始基线：

```text
python project_tool.py --config 本机配置文件完整路径 --request {} --snapshot
```

基线保存在配置文件旁的私有 project-state 目录，不进入交付 ZIP。正常修改时也会在第一次写入前保存基线。模型操作中没有重置基线入口。

在面板“添加本机工具”中选择普通 Python 任务：

- 工具 ID：例如 `project`。
- 程序路径：本仓库 `project_tool.py` 的完整路径。
- 参数每行一个：`--config`、配置文件完整路径、`--request`、`{text}`。
- 用途说明：项目读写与固定测试；输入 JSON，先 `{"action":"inspect"}` 查看格式，通过 test 后 export。
- 勾选“允许 AI 调用此工具”。AI 配置中也需要开启电脑工具。

固定测试由所配置的 Python 解释器执行：`python -X utf8 -u tests/verify_project.py`，工作目录为项目根目录。验证脚本由你提前准备并信任，退出码 0 表示通过；模型不能临时改测试脚本、工作目录、解释器、环境变量或启动参数。测试会导入或执行项目代码，按当前用户权限运行，不能视为执行沙箱。

## 手机使用

例如发送：

```text
/py 运行 ai 给 project 对应项目增加百分比折扣和运费，修改后运行固定测试，通过后把差异、测试报告和源码包发给我
```

QQ 会显示每次项目操作的子任务编号和实际结果。AI 应先读取代码与测试、修改文件，再测试；失败时根据真实错误继续修正。整轮仍受 8 次模型请求、12 次工具操作的预算限制，复杂工作可分轮继续。

项目工具输入为 JSON：

| 操作 | 输入 |
|---|---|
| 文件清单与操作格式 | `{"action":"inspect"}` |
| 读取文件 | `{"action":"read","path":"src/calculator.py","offset":0}` |
| 修改已有文件 | `{"action":"replace","path":"src/calculator.py","sha256":"读取时的完整哈希","content":"完整新内容"}` |
| 查看改动 | `{"action":"diff"}` |
| 运行固定测试 | `{"action":"test"}` |
| 导出并自动回传 | `{"action":"export"}` |

替换时 SHA256 必须与磁盘当前内容一致；文件被别人改过时会拒绝覆盖，需重新读取。测试通过后又修改文件，旧测试结果会失效。导出要求当前清单文件仍与上次通过测试时一致。

## 交付与恢复

export 生成三份附件：`project-changes.diff`、`project-validation.txt`、`project-source.zip`。源码包只包含可读清单文件，不扫描整个项目、不包含私有配置或备份，也不是完整依赖安装包。项目操作成功和业务测试通过是两件事，必须检查 JSON 中的 `passed`，不能只看子任务的“已完成”。

初始文件文本保存在配置旁 project-state 目录的 originals.json，改动也可用差异文件审查。恢复原文件需在电脑核对当前修改后进行，本工具没有自动回滚。项目测试与已授权程序保留正常用户权限，取消不能撤销已发生的操作。
