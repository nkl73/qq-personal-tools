# 在 QQ 使用 ChatGPT 网页和其他 AI

从电脑安装到手机操作的总流程见[完整使用手册](完整使用手册.md)，实际验证状态见[功能清单](功能清单与验证状态.md)。本扩展仅用于 ChatGPT 网页，API AI、Codex、文件和普通工具无需安装。当前手动加载扩展，不存在自动安装向导；源码包只含通用源文件，配对后的扩展由各电脑自行生成。

## 三种独立通道

| 通道 | 登录与凭据 | 新建与继续 |
|---|---|---|
| Codex | 本机 Codex 自己管理已有登录，无需另填 API Key | 继续已保存的会话；或选项目、选模型并确认新建，旧聊天不复制 |
| ChatGPT 网页 | 浏览器当前登录，首次手动安装本机扩展 | 新建普通网页聊天；或选择已打开的普通聊天标签页 |
| 兼容 API 的 AI | 电脑预先配置服务、密钥、模型 | 选模型新建独立对话；继续本次打开的 AI 对话，使用该对话上下文 |

QQ 首页发送 `/py 菜单`，按当前序号操作。“与 AI 对话”中有网页、API 新建和继续对话三个选项；Codex 在首页单列。序号只对当前菜单有效，工作要求仍用文字描述。API 对话不等于 ChatGPT 账号里的普通聊天，记录也不会自动同步到 ChatGPT。

## 首次连接浏览器

1. 保持电脑新版面板运行并连接 QQ。使用 Edge 或 Chrome，手动登录 `https://chatgpt.com/`。使用的是该浏览器当前账号和工作区。
2. 在面板点“ChatGPT 网页通道”，也可运行 `准备ChatGPT网页通道.cmd`。程序在 `.runtime/web-chat/extension` 生成仅属于这台电脑的扩展，打开文件夹。
3. 在 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions` 页面，手动开启开发人员模式，选择“加载解压缩的扩展”，选中上一步的 extension 文件夹。浏览器会显示权限范围，安装由用户确认。
4. 点浏览器右上角“拼图”图标，选择“QQ Personal Tools · ChatGPT 网页通道”，在弹出的白色窗口点“连接此浏览器”，刷新 ChatGPT。扩展管理页的“详细信息”不是连接弹窗。每次只连接一个浏览器配置；换浏览器先在原扩展中断开。
5. 手机 QQ 发 `/py 菜单`，选“与 AI 对话”→“ChatGPT 网页”。按编号新建，或选已打开的聊天，再发送具体要求。

仅安装扩展不等于启用；弹窗“已启用”也不等于手机整链路通过。先发中性短问题，确认手机收到答复，再追问验证上下文。本轮 Edge/Chrome 均已完成新建、追问、重选旧聊天与文字回传，Chrome 另作纯后台复核。跨机和其他网页版本仍需验证，见[本轮报告](全功能测试报告-20261025.md)。

准备扩展后，启动电脑面板会提供仅监听 `127.0.0.1:18770` 的配对队列。扩展带有本机随机配对值，HTTP 请求需鉴权并检查来源和 Host；不监听外网，不要求关闭浏览器安全保护。配对值、网页任务和用户数据均在 `.runtime`，不能发送给他人或打入源码包。

## 使用范围与限制

- 网页适配只操作 `https://chatgpt.com/` 和普通 `/c/` 聊天。历史聊天需要先在电脑浏览器打开，然后从列表选择；不会扫描全部历史。
- 新建页面使用后台标签页，不调用系统键盘或剪贴板。本机 Edge 已验证在另一个空白标签页保持前台时，QQ 连续追问能自动提交并回传，不需要切回 ChatGPT 页面。
- 扩展不读取 Cookie、密码、账号令牌或其他站点。QQ 的文字要求经正常网页提交，读取本次网页答复后送回自己的 QQ 个人账号会话。
- 有未发送草稿、其他生成任务、页面跳转或无法确认答复归属时停止并报错，不覆盖草稿、不自动重复发送。必须确认新用户消息对应本次要求，并等答复稳定且出现完成操作控件，才当作完成。
- 网页、登录验证、网络或扩展重启可能中断。队列已交付的要求不重新派发；发送不确定时先在电脑查看，不能直接认为未执行。
- 停止电脑桥接不保证网页生成也停止。正在生成的内容请在网页确认；本通道不代点网页工具授权，不上传附件，不代表 ChatGPT 可以调用电脑登记的工具。
- 浏览器和电脑面板都须保持运行；网页结构变化可能需要更新扩展。此通道不是官方消息 API，真实稳定性须另行验证。

## 更新和断开

扩展“断开”停止接收新的电脑请求；已有网页生成可能继续。重新生成扩展后，在扩展管理页手动重新加载，并刷新 ChatGPT 页面。所有 API Key 仍只在电脑“添加 AI”设置中填写，不通过 QQ。
