# QQ Personal Tools

**离开电脑，也能用手机 QQ 继续已经接入的工作。**

内置工具可以直接用；选择平台、填写密钥和模型可接入兼容的 AI，无需写脚本。开启电脑工具后，可以用自然语言让 AI 读取共享文字文件、运行已授权程序、生成并回传文件。已有 Python 脚本和命令行程序，在电脑登记一次，就能从手机选择、运行、看进度、查结果和取消。

状态：**v0.9.0 预览版**。主要面向 Windows 10/11 x64、Python 3.10+（需要 tkinter）。内置工具无需模型 API；Codex 沿用本机登录，普通 ChatGPT 通过手动安装的浏览器扩展沿用网页登录，其他远程 AI 使用电脑配置的 API。底层 QQ 连接使用本机 OneBot v11。

## QQ 里的使用菜单

现在有三种对话通道：**Codex、ChatGPT 网页、兼容 API 的 AI**。手机首页选“与 AI 对话”，可选择 ChatGPT 网页、新建 API 对话或继续本次运行的 AI 对话。首页选“继续电脑 Codex”，可继续默认会话、选择其他会话或新建独立对话。

新建 Codex：依次选择已有项目目录、可用模型或电脑默认模型，再确认创建。不会复制旧聊天记录；创建后再发送具体要求，才会开始模型工作。无需关闭桌面里的其他会话。继续某个已被桌面占用的原会话仍受写入权限制。

**桌面应用可以保持打开。** 需要沿用上下文又遇到原会话占用时，按提示选择“手机分支”：从已保存历史建立独立聊天后继续。分支聊天记录不自动合并回原聊天，项目文件仍共用，应避免同时修改同一个文件。分支只在用户明确选择后建立。

**QQ 默认简洁反馈。** 提交要求后主要接收最终答复与文件，必要提问、授权和失败仍会通知。工具步骤、内部任务编号、重复等待提示和结束时重播聊天记录不再默认发送。发送 `/py 消息` 按序号选择简洁或详细；任务菜单可按需查看结果与执行详情，完整记录保留在电脑。

**锁屏可以继续工作，真正睡眠时不能运行。** 新版面板默认勾选“连接手机期间防止自动睡眠”：连接 QQ 时保持主机唤醒，屏幕仍可熄灭；停止连接或退出后恢复原有电源行为，不修改电源计划。本机已完成锁屏下计算、Codex 分支和文件回传，并由手机确认。手动睡眠、休眠、合盖、关机或特殊电源策略仍可能中断；不支持睡眠中继续执行或自动唤醒电脑，见[锁屏与睡眠说明](docs/锁屏与睡眠验收-20261025.md)。

普通 ChatGPT：先在电脑点“ChatGPT 网页通道”，按 [浏览器通道说明](docs/ChatGPT网页通道.md) 安装并连接扩展。QQ 按编号新建普通聊天，或选择浏览器里已打开的聊天；浏览器须持续运行。已在本机 Edge/Chrome 验证新建、已有聊天选择、答复回传和后台追问，网页不必保持前台。这个通道是网页适配，并非官方 ChatGPT 消息 API，页面更新后可能需要更新扩展。

**推荐用编号选择。** 手机发送 `/py 菜单` 后，回复 `/py 1` 这样的序号即可逐步选择 AI、电脑工具、文件和任务。文件名、工具 ID 和任务编号都可以从列表选择，无需复制或手填。选项只在当前菜单内有效，5 分钟后失效；原有指令仍保留。

例如：`/py 菜单` → 选“选择文件” → 选文件 → 选“生成并回传 TXT 概览报告”。与 AI 对话时先选已配置的 AI，再输入实际工作要求。Codex 的会话、继续、占用后重试和单次授权也支持序号；没有选项的工作要求、自由回答和本机密钥仍需填写。

菜单中的“0”返回上一层；首页“0”返回原来选中的对话。打开菜单不会把数字误填到正在等待的程序；返回对话后数字仍可作为正常输入。手机仍需带 `/py` 前缀，当前使用文字编号选择，并非 QQ 原生可点击按钮。

连接成功后只发送一条简短提示。需要时发送 `/py 菜单` 查看首页，或 `/py 菜单 工具` 查看工具用途、示例和反馈；列表按本机实际登记的工具生成。

- `/py 菜单`：随时回到首页。
- `/py 菜单 工具`：当前能做什么；工具多时可发 `/py 菜单 工具 2` 翻页。
- `/py 帮助 calc`：看某项工具的具体输入要求和反馈。把 calc 换成实际工具 ID。
- `/py 菜单 任务`：启动、任务编号、进度、状态、结果和取消。
- `/py 菜单 对话`：多轮回答、空输入、切换会话和本机隐私输入。
- `/py 菜单 文件`：手机发送文件、电脑处理、取回附件和图片显示的方法。
- `/py 菜单 问题`：排队、卡住、报错、编号错误、电脑离线等处理方法。
- `/py 菜单 AI`：直接接入 AI、连续提问、结束会话及上下文范围。
- `/py 菜单 全部`：把全部说明按独立消息发回，方便保存在 QQ 里。

栏目也支持数字 1–6，例如 `/py 菜单 1`。查看菜单不会消耗正在等待的工作回答。任务编号可从任务菜单查看，无需手动复制。若需要把“菜单”等词作为工作内容，使用 `/py 回复 任务编号 菜单`。

[默认菜单完整预览](docs/QQ使用菜单预览.txt)。自定义消息前缀时，菜单中的全部指令会同步替换。

## 不写脚本也能做什么

| 手机消息 | 效果 |
|---|---|
| `/py 菜单` | 查看手机使用首页，按栏目了解工具和操作方法 |
| `/py 设备` | 查看电脑系统、Python 版本和磁盘剩余空间 |
| `/py 运行 calc 12*(3+4)` | 计算常规算式，不执行代码 |
| `/py 运行 text 需要统计的文字` | 返回字符、汉字、英文单词、行数 |
| `/py 运行 files` | 列出电脑共享目录内的文件 |
| `/py 运行 inspect example.csv` | 返回共享目录内常见文件的概况，支持 PDF、Word、Excel、PPTX 和文字等 |
| `/py 格式` | 查看支持的读取格式、限制和组件状态 |
| `/py codex` | 沿用电脑 Codex 登录，选择已有会话、交接后继续项目工作 |
| `/py chatgpt` | 沿用浏览器登录，按编号新建普通聊天或选择已打开的聊天 |
| `/py 运行 fileinfo example.csv` | 生成 TXT 概览报告，并作为附件回传 |
| `/py 文件` | 列出共享目录中的接收文件与任务结果 |
| `/py 发文件 实际共享文件名` | 将共享文件发回自己的手机 QQ |
| `/py 发图片 实际共享图片名` | 将支持的图片直接显示到自己的 QQ 会话 |
| `/py 运行 demo 10` | 体验一项带进度通知的后台任务 |
| `/py 状态` | 查看近期任务及状态 |
| `/py 结果 任务编号` | 查看保存的文字结果 |
| `/py 取消 任务编号` | 请求停止运行中或排队中的任务 |

内置文件功能只读取电脑 `shared/` 目录中的文件，不接受任意电脑路径。新版任务面板已接入 QQ 文件和图片通道；旧单脚本兼容入口仍只处理文字。

## 手机发文件，电脑处理后发回

直接在手机 QQ 中当前已连接的个人账号会话发送文件或图片，收到“附件已保存：inbox/…”后，再把返回的相对文件名交给工具。比如文字文件可用 `/py 运行 fileinfo inbox/实际文件名.txt`，电脑生成 TXT 报告并自动以附件返回。

用 `/py 文件` 查看已接收文件和结果；`/py 发文件 相对文件名` 取回共享目录里的文件；`/py 发图片 相对图片名` 直接发图。成功任务写入专用输出目录的结果也会自动回传，每任务最多 10 个附件。

PDF、DOCX、XLSX/XLSM/XLS、PPTX、RTF、HTML 和常见文本可交给 AI 读取，也可直接用 `inspect` / `fileinfo` 查看。电脑双击 `安装文件读取组件.cmd` 安装 PDF、Excel、RTF 组件即可，无需额外 API。发送 `/py 格式` 查看本机组件状态和限制，完整内容见 [文件格式读取说明](docs/文件格式读取说明.md)。

单文件最多 50 MB，直接显示的 PNG/JPEG/GIF/WebP 图片最多 10 MB；接收目录上限 500 MB。发送未确认时不会自动重发。QQ 后台接受发送不代表手机已经下载。完整步骤见 [文件通道使用说明](docs/文件通道使用说明.md)。

## 先在电脑试用，不必登录 QQ

1. 安装 Python 3.10+，包含 tkinter，将本仓库放到可写目录。
2. 双击 `本机试用.cmd`，或运行 `python task_app.pyw --local`。
3. 选“计算器”，在“本次内容 / 参数”输入 `12*(3+4)`，点击“运行选中工具”。
4. 在“任务与结果”中查看 `84`。选“进度演示”，输入 `10`，可以体验运行进度和取消。
5. 点“共享目录”放入自己的 TXT、CSV 或 JSON，再体验文件概览。

本机试用不启动 QQ 后台。内置离线工具不调用模型或网络；若主动测试或运行已配置的 AI，仍会请求对应服务。它使用独立的临时输入队列端口，不会占用旧桥接的固定队列端口。

## 再连接手机

1. 首次使用托管 QQ 时运行 `安装后台组件.cmd`。它只从 NapCat 官方 GitHub release 下载固定版本并核验 SHA256，不修改系统 QQ 安装目录。
2. 普通电脑 QQ 退出同账号登录。在面板点“QQ 登录”，手机扫码确认。
3. 停止本机试用，点击“连接手机”。在手机当前已连接的 QQ 个人账号会话发送 `/py 菜单`，收到菜单后即可按上表操作。
4. 运行时面板可最小化，不自动打开聊天页、不模拟键盘；不需要桌面 AI 助手保持开启。

已有 NapCat / OneBot？在“QQ 连接设置”中取消托管，填入本机 HTTP 地址、回调端口和相同随机 Token，详见 [OneBot 连接说明](docs/onebot.md)。

## 简单接入 AI

**电脑已经登录 Codex？** 发 `/py codex` 选已有会话，再选择继续原会话或建立手机分支，也可从 Codex 菜单新建独立对话。无需填写 API Key，桌面应用可以保持打开。同一个原聊天仍受写入权限制，遇到占用会保留尚未提交的要求；可明确选择手机分支处理它，或释放原连接后重试。详情见 [QQ 继续电脑 Codex](docs/QQ继续电脑Codex.md)。

电脑点“添加 AI”，选择平台、粘贴 API Key、选择或填写模型，然后点“连接并添加”。程序自动填写地址和名称、分配工具编号，测试通过后加入菜单。名称、固定要求和等待时间收进“更多设置”里。支持列表接口的平台可读取模型；火山方舟需填写已开通的模型或接入点 ID，预设仅用于按量 API。无需自己编写脚本。仅支持 **Chat Completions 兼容文字接口**，不能把任意 API 链接当作兼容接口。

假设程序自动分配的 ID 为 `ai`（以实际菜单为准）：

只有一个 AI 且没有选中的活跃任务时，可以直接发 `/py 你的要求`，自动创建会话。任务结束后再发自然语言也会开始新会话；等待回答时继续同一会话。正在处理时新内容不会自动提交，会提示等待。多个 AI 时会返回选择示例，按工具 ID 指定本次使用的 AI。

- `/py 运行 ai 帮我起草一封邮件`：创建独立 AI 会话并提问。
- `/py 回复 真实任务编号 改得简短一些`：在同一会话继续，保留最近上下文。
- `/py 结束 真实任务编号`：回答完成后结束会话、释放任务名额。
- `/py 取消 真实任务编号`：立即请求停止；本地会停止请求进程，但不能保证服务端同时停止生成或计费。

每次新发“运行”就新建会话。等待提问的 AI 也占一个活跃名额，暂时不用时请结束。失败不会自动重发，请修正后重新提交问题。

密钥默认只在本次打开期间保留。Windows 可勾选“在本机加密记住密钥”，使用当前用户的 DPAPI 加密；不勾选时重开面板需补填。密钥不经过 QQ，问题和最近上下文会发给所配置的服务。

## 让 AI 调用电脑工具

在 AI 设置中勾选“允许 AI 使用共享文件和电脑已授权工具”。模型需支持 Chat Completions function calling；勾选后的连接测试会带上工具定义。普通文字对话仍可单独使用，旧配置默认关闭工具。

手机发送文字文件，等收到保存提示后，可以说：

```text
/py 运行 ai 把最新收到的 TXT 整理成待办清单，保存为文件发给我
```

AI 可以查看最近共享文件，分段读取 PDF、DOCX、Excel、PPTX、RTF、HTML 及常见文字，调用计算和统计等内置工具，生成新的文字文件并自动排队回传。手机发送附件，等收到确认后，可直接发 `/py 阅读本文档，概述内容`（已接入一个 AI、已开启工具且无正在处理的选中任务时）。表格保留工作表和行号，PDF/PPTX 保留页码，缺失内容和公式缓存会明确提示。需要运行自己的普通 Python 或命令行程序时，在电脑编辑该工具，另勾选“允许 AI 调用”。默认 QQ 只接收最终答复、必要问题、错误和文件；工具名称、子任务编号和过程留在电脑日志，选择详细消息时也可发到 QQ。

直接读取的文字最多 1 MB、DOCX 最多 10 MB，PDF/Excel/PPTX 最多 20 MB；全文最多 20 万字，每页最多 12000 字。PDF/PPTX 最多 200 页，Excel 最多 50 张工作表、合计 5000 行、256 列、10 万单元格。扫描件需要 OCR，旧 DOC/PPT 暂需另存为新格式或 PDF；详见格式说明。每个 AI 会话最多生成并回传 10 个文字结果文件。普通文字结果不覆盖原文件；已接入的项目工具可修改明确授权的项目文件。自建程序的运行权限与手动启动一致。交互式程序仍由用户直接通过 QQ 操作。图片识别、网页搜索和任意命令执行尚未接入。

开启工具后，读取的文件和程序输出会发送给所选模型。每轮最多 8 次模型请求、12 次工具操作，总等待上限不超过 10 分钟；已执行工具后的接口失败会保留本轮记录，不自动重跑。取消 AI 会停止它正在运行的子任务，已发生的操作仍保留。详细步骤、边界和接口来源见 [AI 接入与 QQ 使用](docs/AI接入与QQ使用.md)。

## 通过 QQ 修改具体项目

可将 `project_tool.py` 登记为已授权的普通 Python 工具。电脑配置一个项目目录、允许修改的文件和只读的固定测试脚本，AI 就能读取源码、写回改动、查看差异、运行测试，并回传差异文件、测试报告和源码 ZIP。

示例手机要求：`/py 运行 ai 给 project 对应的订单计算器增加折扣和运费，按固定测试验证后发回修改包`。

已用真实 deepseek-flash 完成隔离报价项目验收：源码实际改写，原本失败的固定测试在修改后全部通过（8 项），测试文件未变，手机确认收到三份交付附件。项目工具执行测试会运行修改后的代码，使用当前用户权限；它限制操作范围，不提供执行沙箱。接入步骤见 [项目工具说明](docs/项目工具使用说明.md)。

## 接入已有工具，扩大用途

在电脑点击“添加本机工具”，填写一个短 ID、名称、程序路径和参数，每行一个参数；`{text}` 表示手机本次提交的内容，`{file}` 是经过共享边界检查的输入文件完整路径，`{output}` 是本任务专用输出目录。

| 运行方式 | 适合什么 |
|---|---|
| 普通 Python 任务 | 数据处理、生成报告、文件批处理；不需要 input()，直接运行并返回输出 |
| 交互式 Python | 多步骤询问、已有 AI 对话脚本；支持 input()、print()、本机 getpass() |
| 已安装的命令行程序 | 已有的转换、分析、构建工具，也可以选择 Node 等运行时调用其他语言脚本 |

桥接提供常见文件文字读取，PDF/Excel/RTF 解析库通过组件安装器安装；不附带视频转换、模型或办公软件，这些额外能力由你登记的工具提供。外部工具按固定程序和参数列表启动，手机文字只替换指定参数，不拼接 shell 命令，也不能直接执行手机临时发来的命令。

例如已有 `report.py` 按命令行参数生成报表：选择“普通 Python 任务”，工具 ID 填 `report`，选择脚本和 Python 环境，参数增加一行 `{text}`。手机发送 `/py 运行 report 本月`，任务完成后自动收到文字结果。

工具也能读取环境变量 `QQ_BRIDGE_SHARED_DIR` 和 `QQ_BRIDGE_OUTPUT_DIR`。成功任务写入后者的文件将自动加入 QQ 附件队列，取消或失败任务不会自动回传。普通输出里的文件路径不会触发附件发送。

可指定目标解释器、工作目录、参数和超时。每个工具独立配置，互不覆盖。外部程序输出默认按 UTF-8 解码，也可在工具设置中改用 gb18030 等编码。工具目录只保存在本机 `.runtime/tools.json`，不进入源码包。

## 多轮交互与隐私输入

运行交互工具后，程序的输入提示会带任务编号发回手机。

- `/py 回复 任务编号 内容`：回答指定任务。单独提交空内容可以直接回车。
- `/py 选择 任务编号`：选择一个会话，之后用 `/py 内容` 回答它。
- 同时有多个会话时，显式指定任务编号可以避免答错对象。
- 程序调用 getpass() 时，在电脑面板选中对应任务填写。不同任务和不同提示分别提交，不复用上一项值。

隐私值不进入 QQ 队列或设置文件；桥接在交互输出中遮盖经此面板提交的原始值。它不保证识别脚本从其他位置读取的秘密或经过编码、变形的值。

需要旧版单脚本操作方式时，运行 `启动单脚本.cmd`，详见 [兼容模式](docs/single_script.md)。

## 任务行为与边界

- 同时活跃的任务上限为 2，额外任务排队（最多等待 20 项）；等待输入的长会话也占用名额。菜单、状态、取消不会被长任务阻塞。
- 默认简洁反馈，只发结果与必要问题、错误；`/py 消息` 可选择详细模式，合并、限频显示程序主动输出的进度。交互脚本的输入提示仍分轮回传。
- 完成、失败、超时、取消都会记录状态。重启后把未完成任务记为“中断”，不会重新执行它。
- 本机保存最近 24000 字输出，完成通知最多带最近 6000 字，手机查结果最多带最近 12000 字。
- 取消会尝试停止由该任务启动的进程树；已经发生的文件写入、网络请求等操作不能自动撤销。
- 新版 QQ 收发只接受当前账号自己的个人私聊文字、文件和图片，忽略其他联系人和群聊；发送状态不确定时保存结果，避免重复发送。
- 电脑须开机联网、不能睡眠。普通电脑 QQ 与托管实例不能同时登录同一账号。QQ 后台依赖第三方实现，可能遇到登录失效或协议变化。

**仍不支持接管已打开的 VS Code 终端、全屏 TUI、鼠标操作或任意图形应用。** Python 交互模式主要覆盖 input/print/getpass；直接读写系统输入输出或要求真实 TTY 的程序需要专门适配。

目标工具以本机当前用户权限运行，没有执行沙箱。只登记自己信任的本机程序。`.runtime/` 包含本机登录状态、令牌、工具路径、任务文字和输出，`shared/` 包含共享文件；不要手动公开上传它们。
